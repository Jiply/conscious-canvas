### **E. Observer-Dependent Time System** ✅ **CRITICAL**

**Core Thesis Feature**: "Universe only runs when someone is watching"

#### **Observer Heartbeat System**

**File**: `convex/observers.ts` (NEW)

**Functions**:

1. **`heartbeat(sessionId)`**: Register/update observer presence
   - Called every 5 seconds from frontend
   - Updates `lastHeartbeatAt` timestamp
   - Counts active observers (heartbeat within 15 seconds)
   - Updates `world_settings.observerCount` and `isRunning`

2. **`getWorldState()`**: Query current world state
   - Returns `isRunning`, `observerCount`, `adminEnabled`

3. **`toggleAdmin(enabled)`**: Admin kill switch
   - Force freeze/unfreeze simulation
   - Logs critical events

**Observer Tracking**:

- Each browser tab has unique `sessionId` (stored in localStorage)
- Heartbeat sent every 5 seconds while page is open
- Observer considered "active" if heartbeat within last 15 seconds
- When last observer leaves (tab closed), world freezes

#### **Frontend Observer Hook**

**File**: `hooks/use-heartbeat.ts` (ENHANCED)

**Changes**:

```typescript
// Dual heartbeat system:
// 1. Observer heartbeat (every 5s) - tracks "who's watching"
useEffect(() => {
  async function sendObserverHeartbeat() {
    const result = await convex.mutation(api.observers.heartbeat, {
      sessionId: sessionIdRef.current,
    });
    setObserverCount(result.observerCount);
  }

  sendObserverHeartbeat();
  const interval = setInterval(sendObserverHeartbeat, 5000);
  return () => clearInterval(interval);
}, [convex]);

// 2. Leader tick processing (every 5s) - processes agents
// Only runs if isLeader AND world is running
```

**Returns**:

```typescript
{
  isLeader: boolean,
  stats: { processedAgents, latencyMs, lastTickAt, observerCount },
  observerCount: number,
}
```

#### **Backend Tick Processing**

**File**: `convex/heartbeat.ts` (ENHANCED)

**Key Change**: Check world state before processing agents

```typescript
// Check if world should be running (observer-dependent time!)
const worldSettings = await ctx.db.query("world_settings").first();

if (
  !worldSettings ||
  !worldSettings.isRunning ||
  worldSettings.observerCount === 0
) {
  // World is frozen - no observers watching
  console.log(
    `🧊 World FROZEN: ${worldSettings?.observerCount ?? 0} observers`
  );

  return {
    success: true,
    processedAgents: 0, // No agents processed!
    latencyMs: Date.now() - startTime,
    isLeader: true,
  };
}

// Only process agents if observers are present
const agents = await ctx.db.query("agents").collect();
await Promise.all(agents.map((agent) => processAgentTick(ctx, agent, agents)));
```

**State Transitions**:

```
observerCount: 0 → 1
  → world_settings.isRunning = true
  → Agents start making decisions
  → Event logged: "🌍 Universe awakens"

observerCount: 1 → 0
  → world_settings.isRunning = false
  → Agent processing stops
  → Event logged: "🧊 Universe frozen"
```

## **2. Observer-Dependent Time Flow**

### **Complete State Machine**

```
State 1: FROZEN (No Observers)
  observerCount = 0
  world_settings.isRunning = false
  → Tick processor: Skip agent processing
  → UI: "WORLD FROZEN" banner displayed
  → Agents: Frozen in place, no decisions made

State 2: OBSERVER JOINS
  Browser tab opens → sendObserverHeartbeat()
  → Create/update observer record
  → observerCount: 0 → 1
  → world_settings.isRunning = true
  → Event: "🌍 Universe awakens: 1 observer watching"
  → UI: Banner disappears
  → Agents: Start making decisions

State 3: RUNNING (Observers Present)
  observerCount >= 1
  world_settings.isRunning = true
  → Tick processor: Process all agents
  → Agents: Move, decide, interact
  → Events logged to feed

State 4: OBSERVER LEAVES
  Browser tab closes → heartbeat stops
  → After 15s timeout, observer marked inactive
  → observerCount: 1 → 0
  → world_settings.isRunning = false
  → Event: "🧊 Universe frozen: No observers remain"
  → UI: "WORLD FROZEN" banner appears
  → Agents: Freeze mid-action

State 5: ADMIN FREEZE (Override)
  Admin clicks "Freeze Universe"
  → world_settings.adminEnabled = false
  → world_settings.isRunning = false (even if observers present)
  → Event: "⚙️ Admin disabled simulation"
  → Agents: Frozen regardless of observers
```

## **3. Technical Implementation Details**

### **Observer Table Schema**

```typescript
observer: defineTable({
  sessionId: v.string(),
  lastHeartbeatAt: v.number(),
  metadata: v.optional(v.object({
    userAgent: v.optional(v.string()),
    joinedAt: v.optional(v.number()),
  })),
})
  .index("by_session", ["sessionId"])
  .index("by_heartbeat", ["lastHeartbeatAt"]),
```

### **World Settings Schema**

```typescript
world_settings: defineTable({
  isRunning: v.boolean(),
  observerCount: v.number(),
  adminEnabled: v.boolean(),
  tickHz: v.number(),
  currentTick: v.number(),
  simulationStartedAt: v.optional(v.number()),
  lastTickAt: v.optional(v.number()),
}),
```

### **Events Table Schema**

```typescript
events: defineTable({
  timestamp: v.number(),
  type: v.union(
    v.literal("decision"),
    v.literal("conversation"),
    v.literal("observation"),
    v.literal("world"),
    v.literal("movement")
  ),
  agentIds: v.optional(v.array(v.id("agents"))),
  description: v.string(),
  location: v.optional(v.object({ x: v.number(), y: v.number() })),
  metadata: v.optional(v.object({
    placeId: v.optional(v.id("places")),
    severity: v.optional(v.string()),
  })),
})
  .index("by_timestamp", ["timestamp"])
  .index("by_type", ["type"]),
```

## **4. Performance Characteristics**

### **Observer Heartbeat**

- **Frequency**: Every 5 seconds
- **Timeout**: 15 seconds (3 missed heartbeats = inactive)
- **Overhead**: ~10-20ms per heartbeat
- **Network**: Minimal (small mutation payload)

### **World State Checks**

- **Tick processing**: Checks `world_settings.isRunning` before agent processing
- **Early exit**: If frozen, skips all agent work (~0ms vs ~200-500ms)
- **Cost savings**: No LLM calls, no pathfinding when frozen
- **Log output**: "🧊 World FROZEN: 0 observers, skipping agent processing"

### **Event Logging**

- **Per decision**: ~5-10ms overhead
- **Event feed query**: <50ms for 15 events
- **Storage**: ~200 bytes per event
- **Cleanup**: Optional mutation to delete old events

   - New events appear but feed doesn't scroll to bottom

4. **No event click interaction**:
   - Can't click events to jump camera to location
   - **Future**: Make events clickable

1. **Event table growth**:
   - Events accumulate indefinitely
   - **Future**: Add auto-cleanup for events >1 hour old

   - Each observer sends separate mutation
   - **Future**: Batch multiple heartbeats if needed
